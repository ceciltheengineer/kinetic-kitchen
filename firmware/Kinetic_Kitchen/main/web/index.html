Motor on runs at belt speed until Stop (10 min max). Start your stopwatch once it is up to speed; the counter shows motor and roller revolutions.

Arms

Arm 0 point: nudge each arm until it sits flush with the conveyor, then press Set as 0. Saved in flash.

Servo test 90°

Servo test drives one servo straight to an angle (no 0 point) and reads the signal pin back.

Arm angles: the rest angle (usually 0, flush with the conveyor) and the out angle for one belt direction; the other direction uses 180° minus it. Save moves the arm right away and stores the angles in flash.
